REPOSITORY INTELLIGENCE FOR ENGINEERING TEAMS

Understand code.
Improve what matters.

CodeForge turns a public GitHub repository into a structured engineering review. It builds the code, gathers objective quality signals, and presents the evidence in one focused analysis instead of making you search across disconnected tools and logs.

WHAT CODEFORGE ANALYZES

One repository. A complete technical picture.

01

Build health

Compiles .NET projects and captures structured compiler and Roslyn analyzer findings with severity and source locations.

02

Tests and coverage

Runs trusted .NET tests, reports passed, failed, and skipped counts, and shows the application code exercised by those tests.

03

Code complexity

Uses Lizard to identify complex C#, JavaScript, and TypeScript functions that deserve focused review.

04

Dependencies

Maps .NET project references and JavaScript or TypeScript imports, including cycles and configured architecture violations.

05

Shareable reports

Keeps the Analysis page and downloadable PDF aligned to the same persisted engineering evidence.

WHY IT HELPS

Review risks sooner and make decisions with evidence.

CodeForge gives developers and reviewers a faster way to understand an unfamiliar repository, prioritize maintainability work, spot architectural drift, and communicate quality concerns without exposing one user’s analysis to another.
